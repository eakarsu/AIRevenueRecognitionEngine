# Quarantined Generated Surfaces

The original repository contains broad generated pages and backend routes, including `gap-*` modules and generic AI/chat surfaces. They are retained as prototype reference material only.

`backend/server.js` intentionally mounts only health, tenant authentication, and `routes/governedRevenue.js`. Code outside those mounted surfaces is not a supported product feature, must not be treated as accounting evidence, and cannot post or reconcile revenue. Reintroducing any legacy route requires domain ownership, typed authoritative inputs, durable migrations, access controls, failure semantics, and tests equivalent to the governed workflow.
